# Task Manager Web App

## Description
This project is a simple task manager built using HTML, CSS, and JavaScript.
Users can add, edit, delete, and complete tasks. Tasks are saved using browser localStorage.

## Features
- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Tasks persist using localStorage
- Dark mode toggle

## Technologies Used
- HTML
- CSS
- JavaScript
