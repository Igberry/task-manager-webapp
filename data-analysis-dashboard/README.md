# Data Analysis Dashboard (CSE 310 Module 3)

## Overview

This project is a Data Analysis Dashboard built using Python. It analyzes student performance data and generates insights using statistics and visualizations.

## Features

- Data loading and cleaning using Pandas
- Calculation of averages and summary statistics
- Visualization of:
  - Subject performance
  - Pass/fail distribution
  - Study hours vs performance
- Insight generation from dataset

## Tools Used

- Python
- Pandas
- Matplotlib

## How to Run

```bash
pip install -r requirements.txt
python main.py
```
