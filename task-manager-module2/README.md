# Task Manager – TypeScript

## Description

This module is a TypeScript-based version of the Task Manager web app. It provides the same core functionality as the main app, but is implemented using TypeScript for improved type safety and maintainability. Users can add, edit, delete, and complete tasks, with all data persisted in browser localStorage.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Tasks persist using localStorage
- Modern TypeScript codebase
- Modular structure

## Technologies Used

- TypeScript
- HTML
- CSS
- JavaScript (compiled from TypeScript)

## Usage

1. Compile the TypeScript source files:
   ```
   tsc -p ..
   ```
2. Open `index.html` in your browser (preferably using a local server).

## Notes

- The compiled JavaScript files are output to the `../dist` directory.
- Styles are located in the `styles/` folder.
